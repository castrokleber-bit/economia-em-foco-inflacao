================================================
 Economia em Foco | Inflação — Como instalar
 GPE/ECON · Confederação Nacional da Indústria
================================================

PRÉ-REQUISITO
-------------
Python 3.11 ou superior instalado na máquina.

Para verificar: abra o Prompt de Comando e execute
    python --version

Se aparecer "Python 3.11.x" (ou versão maior), está ok.
Caso contrário, baixe e instale em: https://www.python.org/downloads/
(marque a opção "Add Python to PATH" durante a instalação)


COMO USAR — DIA A DIA
----------------------
1. Extraia o ZIP em qualquer pasta (ex.: Documentos\economia-em-foco-inflacao).
2. Clique duas vezes em  iniciar.bat.
3. Na PRIMEIRA VEZ: aguarde ~1 minuto enquanto as dependências são instaladas.
   Nas vezes seguintes, o servidor sobe em segundos.
4. O browser abrirá automaticamente em http://127.0.0.1:8000.
5. Selecione o indicador (IPCA ou IPCA-15), informe o mês e clique em Gerar nota.
6. Use o botão Copiar para colar no WhatsApp.
7. Para encerrar o servidor: feche a janela preta do iniciar.bat.


OBSERVAÇÕES
-----------
- O app busca os dados diretamente nas APIs do IBGE e do Banco Central.
  É necessário ter acesso à internet no momento da geração.
- A nota só pode ser gerada após a divulgação oficial pelo IBGE
  (IPCA geralmente às 9h; IPCA-15 em data própria).
- Nenhum dado é enviado para fora; o app roda 100% localmente.
- O texto da nota é determinístico (não usa IA). O rascunho de
  "Leitura para a Indústria" (se configurado) requer uma chave
  da API Anthropic no arquivo .env — contate o responsável pelo app.


PROBLEMAS COMUNS
----------------
"Python nao encontrado"
  → Instale Python 3.11+ marcando "Add Python to PATH".

"Falha ao instalar dependencias"
  → Verifique a conexão com a internet e tente novamente.

"Dados não disponíveis para o mês informado"
  → O IBGE ainda não divulgou o resultado. Aguarde a publicação oficial.

"A porta 8000 já está em uso"
  → Outra instância do app já está rodando. Feche e tente novamente.


CONTATO
-------
Em caso de dúvidas, procure o responsável pelo app na equipe de economia.
